# Vertex Welder — Changes

2026-10-06 — Project 0.005: rebuilt the production dialog against the shared MaxScript UI framework. Added the canonical .NET tool title button with LMB/F1 shared restart behavior, removed the duplicate bottom restart button and project-specific restart backend, moved the dialog to the 336 px / 12 px grid layout, and added INI persistence for threshold, weld mode, dialog position, and dialog height through the shared UI helpers. Production and regression filenames/internal project versions advance together to `0.005`; the regression now includes managed-dialog and title-button checks. `design.md` documents the new persistent UI contract.

2026-10-06 — Project 0.004: fixed Edit Poly pair welding against the shared verified target-weld sequence. The destination is moved to the requested weld point first, the source is moved last, the source is explicitly kept as the active vertex selection, then `WeldVertices source_id target_id` is committed and verified by the live vertex-count drop. Added an incomplete-operation guard so a failed pair that changes the live vertex count returns `-1` instead of being reported as a harmless rejected pair. The regression test now prepares each Edit Poly target context before reading counts and creates fully configured Edit Poly fixtures. Production filename, internal file/project version, visible title, regression filename, and regression project version all advance together to `0.004`.

2026-10-06 — Project 0.003: restored version consistency across the production filename, internal file/project version, visible tool title, and regression test. Added `Vertex-Welder_0.003.ms` and `Vertex-Welder-Test_0.003.ms`; the test now loads the matching production version. Fixed Editable Poly weld execution by treating `polyop.weldVerts` as a command result rather than a Boolean: success is verified only by the required live vertex-count reduction. Applied the same correction to sequential Editable Poly border welds and documented the native return-value rule in `design.md`.

2026-10-06 — Project 0.002: fixed the regression fixture helper so its optional Edit Poly flag no longer shadows the protected native `Edit_Poly` class identifier. Renamed the keyword parameter to `add_edit_poly`, switched modifier creation to the verified `Edit_Poly()` plus `.name` pattern, and advanced the executable test to `Vertex-Welder-Test_0.002.ms`. Production `Vertex-Welder_0.001.ms` is unchanged.

2026-10-05 — Project 0.001: initial design and implementation. Added millimeter threshold control; WELD, PER ELEMENT, and sequential BORDERS modes; Editable Poly and Edit Poly support; face-plane-intersection border targets; two-phase TEST button with Listener diagnostics; restart action; and executable regression test coverage for all three modes on both topology targets.
