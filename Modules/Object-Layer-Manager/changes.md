# Changes

- 2026-10-05 — Project 0.084: adds a full-width `Sync` button below Refresh/New Layer. LMB synchronizes the currently displayed branch-rollout UI to scene layers (`rollout.open -> layer.on`) in one undoable scene-state operation. RMB synchronizes scene layer enabled state back to manager state (`layer.on -> rollout.open`): all scene branch layers update remembered rollout state, while currently displayed branch rollouts update immediately, then the open/closed table is persisted. Layer buttons now mirror scene state visually: OFF or hidden layers remain clickable but use gray background/text, while visible ON layers keep the normal dark/light style; the existing last-used bold LMB marker remains independent. Tool-driven visibility/isolation actions refresh button colors immediately. `Object-Layer-Manager-Test.ms` 0.074 adds source checks plus runtime mapping/gray-state tests using a real test layer and a lightweight rollout-state adapter.

- 2026-10-02 — Project 0.083: corrects RMB visibility behavior for real layer trees. Hiding a visible target changes only that clicked layer; showing a hidden/blocked target clears hidden state only on that layer and the required ancestor path. Sibling flags are preserved. The regression test builds `TOP-LAYER > PARENT-LAYER > LAYER-A / LAYER-B` and verifies toggling `LAYER-B` never changes `LAYER-A`.

- 2026-10-02 — Project 0.082: highlights the last layer button successfully used by **LMB** with a bold 9 pt font while every other visible layer button stays regular 9 pt. The last-used native layer name is persisted per scene in the existing INI and restored after hierarchy rebuilds/Refresh/Restart when that layer is visible. Failed LMB moves do not change the marker, and CTRL+RMB context-menu Add Selection remains outside the LMB-only highlight contract. `Object-Layer-Manager-Test.ms` 0.072 adds regression checks for bold/regular font states, last-used persistence, button registration, and success-gated LMB updates.

- 2026-10-02 — Project 0.081: remembers every generated branch rollout's open/closed state per scene and native layer name. Dynamic rollout `rolledUp` callbacks persist state into the existing Object-Layer-Manager INI table, and hierarchy rebuilds/Source changes/Restart restore that state through `addSubRollout ... rolledUp:`. The layer-button RMB visibility scope is explicitly locked to the clicked layer plus its non-Default ancestor chain only; children and siblings are never directly traversed or assigned. `Object-Layer-Manager-Test.ms` 0.071 adds regression checks for rollout-state persistence/restoration and for ancestor-only RMB traversal.

- 2026-10-02 — Project 0.080: fixes the `New Layer` runtime failure where the unsupported `getString` call resolved to `undefined`. `Object-Layer-Manager.ms` now uses a native modal MAXScript rollout with a single-line `editText` for the prefilled `{Current-Layer}-NEW` name prompt; Cancel/Escape returns without changing the scene. LMB nested placement, RMB sibling placement, selection movement, and the 0.079 parent-chain visibility behavior are unchanged. `Object-Layer-Manager-Test.ms` 0.070 rejects the old `getString` path and checks the native modal prompt wiring.

- 2026-09-28 — Project 0.079: layer-button RMB now shows/hides the clicked layer together with its full non-Default parent chain. If any layer in the chain is hidden, RMB shows the whole chain; if the whole chain is visible, RMB hides it. The special Default/native `0` root is not pulled into normal child-layer chains, while RMB on Default still toggles Default itself. The CTRL+RMB visibility menu action uses the same chain behavior, and tooltips/menu wording are updated. `Object-Layer-Manager-Test.ms` 0.069 adds source regression checks for chain collection, Default exclusion, shared visibility state, and updated tooltips.

- 2026-09-28 — Project 0.078: `New Layer` now has two creation modes. LMB creates the new layer nested under the layer containing most selected objects; RMB creates it next to that current layer by using the current layer's parent, with top-level current layers producing top-level siblings. Both modes pre-fill `{Current-Layer}-NEW`, move all selected objects into the new layer, and refresh the hierarchy after success. The button tooltip documents LMB and RMB separately. `Object-Layer-Manager-Test.ms` 0.068 adds static regression checks for both creation paths and the RMB tooltip.

- 2026-09-28 — Project 0.077: renames the top `Create` button to `New Layer`. Resize handling is simplified for the fixed 256 px dialog: the recursive dynamic-rollout width relayout and all resize-time width assignments are removed. `resizeHierarchySlot()` now changes only hierarchy height and the Restart Y position, and only when those values actually differ, preventing width-change resize events from repeatedly redrawing the full hierarchy. `Object-Layer-Manager-Test.ms` 0.067 adds regression checks for the new caption and removal of width-driven relayout.

- 2026-09-28 — Project 0.076: `Object-Layer-Manager.ms` changes the literal main rollout caption to `Object-Layer-Manager | v0.076` so the dialog title matches the canonical filename basename exactly. No runtime title mutation or other UI behavior changes. `Object-Layer-Manager-Test.ms` 0.066 updates the literal/runtime title regression checks.

- 2026-09-28 — Project 0.075: the project/tool is renamed from `Scene-Layers-Sorter` to `Object-Layer-Manager` across the canonical script/test filenames, UI title, restart/INI paths, project folder/docs, and version snapshots. The fixed 256 px top action row now uses native `across:2` layout for equal-width `Refresh Layers` and `Create` buttons; the old vertical-resize assignment that expanded Refresh across the Create button is removed. `Object-Layer-Manager-Test.ms` 0.065 adds static/runtime checks for the two-column top row.

- 2026-09-28 — Project 0.074: the project/tool is renamed to `Object-Layer-Manager` across the canonical script/test filenames, UI title, restart/INI paths, project folder/docs, and current version snapshots.
