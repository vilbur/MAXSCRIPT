GPT ↔ MCP ↔ 3ds Max Bridge

Pracovní poznámka k plánovanému propojení ChatGPT s 3ds Maxem. Google Drive zůstává úložiště verzovaných MaxScriptů; MCP slouží jako pracovní komunikační kanál.

Cílový data flow

ChatGPT
napíše/upraví MaxScript a vyvolá MCP nástroj
↕ HTTPS / vzdálené MCP
MCP endpoint / bridge na PC
převezme požadavek z internetu a předá ho lokálnímu 3ds Max MCP řešení
↕ lokální komunikace
3ds Max MCP server / bridge
spustí příkaz nebo MaxScript v 3ds Maxu
↕
3ds Max
provede skript → vytvoří výsledek / JSON / log
↑ výsledek stejnou cestou zpět
ChatGPT
zpracuje feedback → vytvoří další verzovanou iteraci

Google Drive

Každá iterace skriptu se uloží jako nová verze, např. Tool_0.01.ms, Tool_0.02.ms. Poslední funkční baseline se nepřepisuje. Drive je historie a záloha; není nutné, aby byl transportní vrstvou mezi GPT a Maxem.

MCP řešení pro 3ds Max

3dsmax-mcp — GitHub
Kandidát s nativním bridge pro 3ds Max a MCP serverem.

Max Ultra MCP — GitHub
Alternativní řešení používající MaxScript bridge a lokální MCP server.

Krátký postup

  1. Nainstalovat a lokálně otestovat vybrané MCP řešení s 3ds Maxem.
  2. Ověřit: příkaz → spuštění MaxScriptu → návrat výsledku/logu.
  3. Ověřit, jak připojit vlastní vzdálený MCP endpoint přímo k ChatGPT.
  4. Teprve potom zvolit bezpečné HTTPS zpřístupnění lokálního MCP serveru.
  5. Napojit vývojový cyklus na verzované MaxScripty uložené na Google Drive.
Stav 9. 10. 2026: Lokální MCP projekty jsou kandidáti pro komunikaci s 3ds Maxem. Vzdálená cesta ChatGPT → HTTPS → PC → MCP je cílová architektura, ale před implementací je potřeba ověřit konkrétní podporu vzdáleného MCP v ChatGPT a způsob bezpečného vystavení endpointu.
