# Main-Toolbar-Extended

A dockable toolbar for Autodesk 3ds Max that gives direct access to commonly used transform and snapping settings. See which modes are active and change them without opening nested menus.

## Main features

- **Transform centres:** Pivot, Selection, and Transform Coordinate Centre.
- **Reference coordinate systems:** View, World, Local, Gimbal, Parent, Pick Object, and Constant Reference System.
- **Axis constraints:** X, Y, Z, XY, YZ, and ZX.
- **Snapping:** Grid Points, Vertex, Pivot, Midpoint, Bounding Box, and Centre Face; 2D, 2.5D, and 3D snap modes; master Snap toggle and Angle Snap.
- **Fast visual feedback:** Icon-only snap buttons with tooltips and active-state indicators.
- **Flexible placement:** A single toolbar that can be floated or docked alongside the main toolbar.
