# Changes

## 2026-10-05

- Added `Wall-Cleaner-Checklist_0.01.ms` with per-block checklist presets, scene-persistent state, Main Pipeline checklist, reset control, restart support, and a non-destructive persistence test function.
- Added `Wall-Cleaner-Checklist_0.02.ms` synced to the current `Wall-Cleaner-Workflow.md` Main Pipeline: 21 checklist items, `WALL GEOMETRY CHECK`, removal of legacy `BORDER CORNER CHECK` / `CHECK EXTRUSION`, and safe migration of saved 0.01 checklist states.
- Added `Wall-Cleaner-Checklist_0.03.ms`: closes all older Wall Cleaner Checklist dialogs on initialization, fixes rollout callback ordering that caused `updateProgress` to resolve as undefined, keeps a stable rollout-local checklist model reference to avoid undefined model calls, and adds a targeted API regression test.
- Added `Wall-Cleaner-Checklist_0.04.ms`: replaced undefined `getString` calls with the verified `MaxCustomControls.RenameInstanceDialog` text-entry helper for NEW / RENAME block actions; preserved old-dialog cleanup on initialization.
- Added `Wall-Cleaner-Checklist_0.05.ms`: replaced checklist captions with clickable .NET labels, changes each label font color to green when its checkbox is checked, keeps unchecked labels in the default light UI color, and retains native Boolean two-state checkboxes only.
- Added `Wall-Cleaner-Checklist_0.06.ms`: .NET checklist labels now inherit their actual parent control background color so they match the native 3ds Max dark UI while keeping green text for checked items.
- Added `Wall-Cleaner-Checklist_0.07.ms`: fixed .NET label background initialization by reading the native 3ds Max `colorMan #background` color directly instead of dereferencing an undefined WinForms parent; checked labels still use green text.
- Added `Wall-Cleaner-Checklist_0.08.ms`: synchronized checklist items to the latest `Wall-Cleaner-Workflow.md` Main Pipeline, adding the five MODEL SETUP steps for a total of 26 items and safely migrating existing 21-item and legacy 22-item saved states.
- Added `Wall-Cleaner-Checklist_0.09.ms`: merged NEW / RENAME / DELETE block controls into one `NEW / EDIT` button beside the block dropdown; LMB creates a block, RMB opens a Rename / Delete menu, and Delete requires confirmation.
- Added `Wall-Cleaner-Checklist_0.10.ms` and updated `Wall-Cleaner-Workflow.md`: removed the block dropdown caption; synchronized EXTRUDE WALLS order to the latest workflow; merged final post-process validation into one READY item; checking READY now runs automatic STL Check on selected final geometry, and READY is saved only when the full STL validation returns no error faces (including no open-edge failures); legacy READY flags are cleared during migration so they must pass the new validation.
- Added `Wall-Cleaner-Checklist_0.11.ms` and updated `Wall-Cleaner-Workflow.md`: removed redundant `ASSIGN MODEL TO BLOCK / PARENT LAYER`; `CREATE PARENT LAYER` now auto-checks when a same-name layer exists; `CREATE MODEL NODE` auto-checks when a `Text` node has `.text` equal to the active model name; `SYNC LAYER / MODEL NODE / PRESET NAME` auto-checks only when the matching layer, Text model node, and pipeline preset all exist. Scene-derived setup checks refresh automatically while the rollout is open.
- Added `Wall-Cleaner-Checklist_0.12.ms`: fixed the 0.11 24-item UI-state mapping regression that duplicated MODEL SETUP item 4 and produced a 25-value UI state; this broke refresh after NEW / RENAME and made new or renamed presets appear not to work. UI state, label-color arrays, and state restore now map exactly 24 unique checklist items, with a regression count check in the UI test.
- Added `Wall-Cleaner-Checklist_0.13.ms`: added `Wall-Cleaner-Presets.ini` as the authoritative development preset store, persistent across and independent of `.max` scenes. The INI stores preset names, active preset, and all 24 checklist states; the current scene helper is still written as a mirror so scene persistence can be compared. On first use without valid INI data, existing scene preset data seeds the INI. The persistence test now reports INI status, scene-helper presence, and scene-mirror agreement.
- Added `Wall-Cleaner-Checklist_0.14.ms`: fixed NEW / RENAME preset confirmation by using the .NET dialog result directly via `ToString()` instead of the invalid MAXScript string cast that could return `undefined` after pressing OK; added explicit duplicate/empty-name checks and Listener diagnostics that distinguish input errors from INI write failures.
